# simpleapps2

A simple Hello World web app built with Node.js (no dependencies).

## Requirements

- Node.js 18+

## Run

```bash
npm start
```

Then open http://localhost:3000. Set `PORT` to use a different port.

## Endpoints

- `GET /` – Hello World page
- `GET /health` – returns `{"status":"ok"}`

## Test

```bash
npm test
```
